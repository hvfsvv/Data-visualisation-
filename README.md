# Projet d'Analyse de Données Foncières : Île-de-France/Paris

## Description
Ce projet vise à analyser les données foncières de la région Île-de-France afin d'identifier les meilleures opportunités d'investissement immobilier. Il s'appuie sur des critères comme la valeur des biens et leur emplacement.

## Objectifs
- Comprendre la dynamique du marché foncier en Île-de-France
- Identifier les zones à fort potentiel d’investissement
- Visualiser les tendances régionales

## Sommaire du Notebook
1. **Présentation des données**
2. **Nettoyage des données (Data Cleaning)**
3. **Extraction des informations clés (Data Mining)**
4. **Visualisation et exploration des données**
5. **Conclusion**

## Prérequis
- Python 3
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Exécution
1. Clonez ce repo :
    ```bash
    git clone <url_du_repo>
    ```
2. Lancez le notebook :
    ```bash
    jupyter notebook "Data_Vizualisation_Project.ipynb"
    ```

## Résultats Attendus
- Cartes et graphiques illustrant la répartition des biens
- Identification des zones à forte rentabilité
- Analyse des tendances régionales du marché foncier
